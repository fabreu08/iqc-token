# IQC Token Browser Deployer (Local)

This is a local development tool for connecting your browser wallet (MetaMask, etc.) and interacting with deployment flows.

**Note**: Full deployment of the token + multiple allocation contracts from the browser is complex and not yet fully implemented here for safety and reliability reasons.

## Recommended Approach

For now, use the Hardhat Ignition deployment from the command line (see root `DEPLOYMENT_GUIDE.md`).

This folder exists as a foundation for a future friendlier web interface.

## Running Locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173 and connect your wallet.
