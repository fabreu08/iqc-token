## Research Focus

This body of work explores:
- Severity calibration across different AI models
- Limitations of multi-model "consensus" in security reviews
- Distinguishing real vulnerabilities from tokenomics/credibility issues
- Methodological requirements for credible LLM-assisted audits
- The gap between textual analysis and actual code verification

Part of the broader Immutable Quality Control project research.
